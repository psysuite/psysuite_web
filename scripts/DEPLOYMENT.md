# PsySuite Web Manager - Complete Deployment Guide

## Quick Start

The PsySuite Web Manager is **production-ready** with project-based access control. Choose your deployment method:

### 🚀 Docker Deployment (Production)
```bash
# Complete deployment with database setup
./deploy.sh docker

# Check deployment status
./deploy.sh status

# Database management
./scripts/db/prod_recreate_db.sh
./scripts/db/prod_add_testbis.sh
```
**Result**: App running at `http://localhost` with admin login: `alberto.inuggi@gmail.com` / `antares`

### 🔧 Traditional Development (PyCharm)
```bash
# Development deployment with local database
./deploy.sh traditional

# Or run debug server directly
python scripts/run_debug.py
```
**Result**: Development server at `http://localhost:5001`

### Option 2: VPS Production Deployment

#### Prerequisites
- Ubuntu 20.04+ VPS (e.g., Aruba)
- Domain pointing to VPS IP
- SSH access to VPS

#### Step-by-Step VPS Deployment

1. **Setup VPS**
   ```bash
   # Connect to VPS
   ssh root@your-vps-ip
   
   # Install Docker
   curl -fsSL https://get.docker.com -o get-docker.sh
   sh get-docker.sh
   sudo apt install docker-compose
   ```

2. **Upload Project**
   ```bash
   # From local machine
   scp -r web_app/ root@your-vps-ip:/root/
   ```

3. **Configure Environment**
   ```bash
   # On VPS
   cd web_app
   
   # Edit production settings
   nano .env.docker
   ```
   
   **Critical Settings to Change:**
   ```bash
   SECRET_KEY=your-very-secure-secret-key-here
   POSTGRES_PASSWORD=your-secure-db-password
   ADMIN_PASSWORD=your-secure-admin-password  # Change from 'antares'
   ```

4. **Deploy**
   ```bash
   ./deploy.sh docker
   ```

5. **Verify Deployment**
   ```bash
   curl http://your-vps-ip/api/health
   ./deploy.sh status
   ```

#### SSL Setup (HTTPS)

```bash
# Install certbot
sudo apt install certbot

# Stop containers temporarily
docker-compose down

# Open firewall ports
sudo ufw allow 80/tcp
sudo ufw allow 443/tcp

# Get certificate
sudo certbot certonly --standalone -d your-domain.com

# Copy certificates
sudo cp /etc/letsencrypt/live/your-domain.com/fullchain.pem ssl/
sudo cp /etc/letsencrypt/live/your-domain.com/privkey.pem ssl/

# Update nginx config for HTTPS
cp scripts/nginx-ssl.conf nginx.conf

# Restart with SSL
./deploy.sh docker
```

### Option 3: Shared Hosting (Aruba)

## Environment Management

### Environment Files
- **`.env.docker`** - Docker/production configuration
- **`.env.development`** - Traditional development configuration  
- **`.env`** - Active configuration (auto-generated by deploy.sh)

### Environment Switching
```bash
# Full deployment (includes environment switching)
./deploy.sh docker          # Production deployment
./deploy.sh traditional     # Development deployment

# Environment switching only (no deployment)
./deploy.sh env-docker      # Switch to Docker environment
./deploy.sh env-dev         # Switch to development environment

# Check current environment
./deploy.sh status
```

### Key Configuration Settings

#### Development (.env.development)
```bash
FLASK_CONFIG=development
DATABASE_URL=postgresql://psysuite_user:psysuite123@localhost:5432/psysuite_dev
DEBUG=True
```

#### Production (.env.docker)
```bash
FLASK_CONFIG=production
DATABASE_URL=postgresql://psysuite:${POSTGRES_PASSWORD}@db:5432/psysuite_web
DEBUG=False
SECRET_KEY=${SECRET_KEY}
```

## Troubleshooting

### Check Current Status
```bash
./deploy.sh status
```

### Docker Issues
```bash
# Complete cleanup (removes everything)
./scripts/docker-cleanup.sh

# Redeploy from scratch
./deploy.sh docker

# Manual cleanup
docker-compose down
docker volume rm web_app_postgres_data
```

### Database Issues
```bash
# Complete development cleanup (venv + database)
./scripts/dev-cleanup.sh

# Development database issues only
python scripts/db/dev_recreate_db.py

# Production database issues
./scripts/db/prod_recreate_db.sh

# Check database connection
docker-compose exec db psql -U psysuite -d psysuite_web -c "SELECT version();"
```

### Environment Issues
```bash
# Check active environment
cat .env

# Switch environment
./deploy.sh env-docker      # Switch to Docker
./deploy.sh env-dev         # Switch to development

# Force environment switch with deployment
./deploy.sh docker          # Full Docker deployment
./deploy.sh traditional     # Full development deployment
```
